# bigdata-ai-coursework

《大数据与人工智能》课程作业仓库。

## 目录结构

```
bigdata-ai-coursework/
├── assignments/   # 每次作业一个子目录，按 assignment-01、assignment-02 ... 命名
├── notes/         # 课程笔记与知识点整理
├── datasets/      # 作业用到的数据集（大文件不入库，见 .gitignore）
└── README.md
```

## 环境

- Python 3.13.12
- Jupyter / PySpark（按作业需要安装）
- Git 2.55.0

## 提交规范

每次作业完成后提交一次，commit message 形如：

```
assignment-01: 完成数据清洗与词频统计
```
